# Phase 1 実機検証結果

検証日: 2026-09-08

## 結果概要

Raspberry Pi Pico 2 H、10 kΩ Bカーブ・ポテンショメータ1個、CircuitPython 10.3.0、macOS 15.7.3 の構成で Phase 1 を実機検証した。

- USB MIDI として起動し、USBの抜き差し後も再認識された。
- MIDI Monitorで Channel 1 / CC 20 を受信した。
- ノブ全域で CC 0〜127を連続的に送信した。
- ノブ停止中に不要なCCの連続送信はなかった。
- 0.1 µFコンデンサにより、中央付近の生ADCジッター幅が624から176へ減少した。
- デフォルトのしきい値256、平滑化係数0.25、ポーリング間隔5 msで、明らかな遅れや引っ掛かりはなかった。

以上から、Issue #2 の完了条件を満たす結果と判断する。

## ADC実測

各測定はCircuitPython REPLからGP26を5 ms間隔で1000回（約5秒間）読み取り、最小値、最大値、差を記録した。中央位置は目視による概位置のため、コンデンサ有無では絶対値でなくジッター幅を比較する。

| コンデンサ | ノブ位置 | ADC最小 | ADC最大 | ジッター幅 |
| --- | --- | ---: | ---: | ---: |
| なし | 反時計回り端 | 64 | 240 | 176 |
| なし | 中央付近 | 37769 | 38393 | 624 |
| なし | 時計回り端 | 65311 | 65535 | 224 |
| 0.1 µFあり | 反時計回り端 | 0 | 176 | 176 |
| 0.1 µFあり | 中央付近 | 34136 | 34312 | 176 |
| 0.1 µFあり | 時計回り端 | 65535 | 65535 | 0 |

実測した全体範囲は、コンデンサなしで64〜65535、コンデンサありで0〜65535だった。

## MIDI受信結果

- [x] 反時計回り端で Channel 1 / CC 20 / value 0を受信した
- [x] 時計回り端で Channel 1 / CC 20 / value 127を受信した
- [x] 端から端まで回したとき、0から127まで連続的かつ単調に変化した
- [x] 逆方向へ戻したときも連続的に変化した
- [x] 中央付近で停止後、不要なCCの連続送信はなかった
- [x] 0.1 µFコンデンサ装着後、60秒間停止しても追加送信はなかった
- [x] 素早い操作を含め、明らかな遅れ、引っ掛かり、操作しづらさはなかった

コンデンサありの記録では、CC 0から127までの上昇を `21:08:48.690`〜`21:08:51.140` に受信し、中央付近へ戻した最後のCC 67を `21:08:53.324` に受信した。その後の60秒間に追加送信はなかった。

## 0.1 µFコンデンサの比較と採用判断

コンデンサなしでも、しきい値256と平滑化係数0.25により、MIDIレベルでは停止中の大量送信は発生しなかった。一方、GP26とAGND間へ0.1 µFを追加すると、中央付近の生ADCジッター幅は624から176へ約72%減少し、操作感の悪化もなかった。

このため、Phase 1の実機構成では0.1 µFコンデンサありを採用する。しきい値と平滑化係数はデフォルト値のままとする。
